# SRS Community

Share SRS with its community, such as in a community meeting, a report of the changes, or a live stream.

## Report Period

- The default period of a report is the last calendar month.
- The user may ask for a quarter, a half year, a year, or exact dates.
- Use exact dates in every report, such as `2026-10-01 to 2026-10-31`.

## Task Router

Route the request to one task, and load its reference:

- **Report and slides**: summarize the period's changes into a text report and a slide deck. → [references/report-and-slides.md](references/report-and-slides.md)
- **Live stream**: set up OBS and stream a meeting or any other live session. → [references/obs-live-stream.md](references/obs-live-stream.md)

## Rules

- 🔒 This skill is public. Never write a stream key, meeting ID, device ID, host name or local path into the repository.
- Facts come from commits, pull requests and the code. Never invent a number, a quote or a name.
